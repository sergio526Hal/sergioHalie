🚀 ÉTAPES D'INSTALLATION
═══════════════════════════════════════════════════════════════════════════

ÉTAPE 1: Créer les dossiers
   → Créer le dossier "images" dans le dossier portfolio

ÉTAPE 2: Ajouter les images
   → Placer "profile.jpg" dans images/ (votre photo de profil)
   → Placer "projet1.jpg" dans images/ (screenshot Heytens Boutique)
   → Placer "projet2.jpg" dans images/ (screenshot Whisky Shop)
   
   Dimensions recommandées:
   - profile.jpg: 300x300px ou plus
   - projet1.jpg & projet2.jpg: 600x400px ou 800x600px
   
   Format: JPEG ou PNG

ÉTAPE 3: Ajouter le CV
   → Placer "Cv.pdf" dans le dossier racine (où se trouve index.html)
   → Le PDF sera téléchargeable via le bouton "Voir mon CV"

ÉTAPE 4: Ouvrir le portfolio
   → Double-cliquer sur "index.html" OU
   → Ouvrir dans un navigateur (Ctrl+O ou Cmd+O)

❓ DÉPANNAGE
═══════════════════════════════════════════════════════════════════════════

Les images ne s'affichent pas?
  → Vérifiez que le dossier "images/" existe
  → Vérifiez que les fichiers sont au bon endroit
  → Vérifiez les noms: profile.jpg, projet1.jpg, projet2.jpg

Le formulaire ne fonctionne pas?
  → Vérifiez que js/script.js est bien lié dans contact.html
  → Ouvrez la console (F12) et cherchez les erreurs

Le CV ne se télécharge pas?
  → Vérifiez que Cv.pdf est dans le dossier racine
  → Essayez avec un autre PDF

Les styles ne s'appliquent pas?
  → Vérifiez que css/style.css est bien lié dans chaque HTML
  → Rechargez la page (Ctrl+F5)
